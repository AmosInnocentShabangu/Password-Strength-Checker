# Password-Strength-Checker
This project is a simple password strength checker written in Bash and python

## Overview
This project is a simple password strength checker written in Bash.
It helps users understand basic password security by validating
password length and complexity.


---

## Features
- Checks password length
- Requires uppercase and lowercase letters
- Requires numbers
- Requires special characters
- Hides password input for privacy

This project is a simple Python-based password strength checker.
It evaluates password complexity based on common security rules.

This project does NOT perform hacking or password cracking.
It is intended for educational purposes only.

---

## Features
- Minimum password length check
- Uppercase and lowercase validation
- Numeric character requirement
- Special character validation
- Hidden password input
